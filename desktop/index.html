GETTING STARTED

5 分钟完成 ChatGPTX 设置

按顺序完成下面四步即可。平时使用时只需要打开 ChatGPTX，Tunnel 会保持到你主动停止或关闭程序。

1

准备 Tunnel ID

进入 OpenAI Platform 的 Tunnels 页面，创建一个 Secure MCP Tunnel，然后复制以 tunnel_ 开头的 ID。

2

准备 Runtime API Key

创建用于 Tunnel 的 Runtime API Key。建议使用受限 Key，并只授予 Tunnel 所需权限。你可以选择用 Windows DPAPI 安全保存。

3

选择允许目录

在“权限”页面点击“选择文件夹”。只添加你确实希望 ChatGPT 读取或修改的项目目录。通常不需要开启完整文件系统访问。

4

连接并验证

回到“连接”页面填写 Tunnel ID 和 Runtime Key，点击“连接并启动”。状态变为 running 后，再运行一次诊断确认所有组件正常。

推荐权限

日常开发优先使用“开发”模式 + 指定允许目录。只有明确需要运行本地命令时再开启 Shell；只有确实需要跨多个磁盘任意访问时才开启完整文件系统。
