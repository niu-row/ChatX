1 · 注册一台电脑

生成注册码后，在电脑打开 ChatX → 设置 → Relay 与电脑注册，粘贴并注册。无需填写 Desktop ID 或传递管理密钥。

10 分钟有效，仅能使用一次。注册完成后可关闭此页面。

2 · 选择 ChatGPT MCP 主机

电脑注册后会出现在这里。一个域名同时转发到一台 MCP 主机；手机监控可以连接多台电脑。

电脑版本 / 已配对手机ChatGPT MCP

3 · 在 ChatX 启动需要的连接

  1. ChatGPT：连接 → HTTPS MCP → 原生 WSS Relay → 启动 HTTPS MCP。然后将域名的 /mcp 地址添加到 ChatGPT。
  2. 手机：手机连接 → 开启手机监控；再到设置 → Relay 与电脑注册，打开手机公网 Relay 并应用。
  3. 回到本页刷新。MCP 显示“已连接”、手机在线电脑数大于 0，即可分别确认对应通道。
